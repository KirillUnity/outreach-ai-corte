# Screenshot checklist

Capture these yourself. This folder does not store PNG, GIF, or video files. Frame size **1920×1080**. Do not show `.env`, API keys, webhook URLs, or the Neo4j password. Close the editor if a secret is on screen.

Suggested filenames (create them locally; do not commit large binaries):

- [ ] `/dashboard` — `docs/demo/01-dashboard.png`
- [ ] `/companies/:domain` — research result and recommended targets — `docs/demo/02-company-research.png`
- [ ] `/persons/:id` — email candidates with one row marked PRIMARY — `docs/demo/03-person-email-primary.png`
- [ ] `/graph` — `docs/demo/04-graph.png`
- [ ] `/warmup` — mailbox card and timeline — `docs/demo/05-warmup.png`
- [ ] `/articles` — preview of a generated draft — `docs/demo/06-articles.png`
- [ ] Swagger `/docs` — `docs/demo/07-swagger.png`
- [ ] Langfuse UI, only if keys exist (optional) — `docs/demo/08-langfuse-optional.png`
- [ ] Neo4j Browser, only if Neo4j is running (optional) — `docs/demo/09-neo4j-optional.png`
