Ты дорабатываешь Outreach AI Cortex (этот репозиторий). Стек: Python 3.12, FastAPI, async SQLAlchemy, Poetry, Docker Compose. 8 ГБ RAM. Облачный LLM или учебный режим. Локальных моделей, брокера, Kubernetes и живого SMTP нет.

УЖЕ ЕСТЬ, ЭТО НЕ ВТОРОЙ ПРОДУКТ
- POST /api/v1/companies/ — имя, description, домен
- POST /api/v1/persons/ — имя, title, company_id
- POST /api/v1/agent/outreach — LangGraph, по умолчанию AGENT_REQUIRE_HUMAN_APPROVAL=true, решение hold

- README.md на английском, длинный. Не переписывай его в обзор всех экранов

СДЕЛАТЬ

1. Видимый результат одного прогона.
   В AgentRunResponse добавь поле, которое человек читает без знания кода:
   - учебный режим (LLM_MODE=mock): строка ровно «учебный прогон, модель не вызывалась», estimated_cost_usd = 0, сеть не открывается
   - боевой режим (LLM_MODE=real): этой строки нет; стоимость этого прогона считается CostTracker по уже существующей таблице цен на фактическую модель ответа
   Ноль в учебном режиме — штатный исход, не ошибка и не «бесплатный боевой вызов».
   Прайсы gpt-4o-mini и gpt-4o не обнулять.
   Поле прокинь и из живого state, и из сохранённого agent_runs (final_state или явная колонка — как проще, без ломки старых строк: отсутствие пометки у старых прогонов не должно падать 500).

2. Боевой сбой не маскируется.
   Если облачный вызов в real не удался (нет ключа, исключение клиента), ответ остаётся с ошибкой этого шага. Заготовленный текст «Quick idea for your team» и любой другой mock-черновик в этот ответ не подставляются. Учебный режим при этом сам не включается задним числом.
   На показном пути — один облачный chat completion. Второй вызов модели и цикл «переписать грязный черновик» для этого пути не добавляй. Уже существующий validate-retry в графе не расширяй.

3. Подтверждение человека.
   AGENT_REQUIRE_HUMAN_APPROVAL остаётся true по умолчанию. На этом пути решение — hold («ждать подтверждения»). Эндпоинта и кнопки, которые отправляют письмо, не добавляй. save_and_send не вызывается, пока решение hold.

4. Описание в README.
   Сразу после блока Quick start вставь короткую секцию «Один прогон». Читатель проходит только её, без остальных экранов.
   Шаги на существующих ручках, учебный режим:
   - создать компанию: домен и текст о компании (name, description)
   - создать человека в этой компании: имя и текст о роли (title)
   - POST /api/v1/agent/outreach с person_id и sender_name / sender_title / sender_company
   В секции покажи пример ответа полями: subject, body, decision=hold, estimated_cost_usd=0, пометка «учебный прогон, модель не вызывалась».
   Одной фразой: в боевом режиме уходит один облачный запрос, цена берётся из таблицы CostTracker; если запрос не удался, черновик не подменяется удачным текстом.
   Одной фразой: письма наружу нет.
   Не добавляй curl отправки, Instantly, SMTP, обход /dashboard, /articles, /warmup.

5. Тест backend/tests/test_demo_run_label.py
   - mock-прогон (или прямой вызов генератора/клиента в mock, если полный граф в тесте требует Postgres): стоимость 0, в ответе есть точная пометка, subject/body заполнены, decision hold там, где вызывается decide
