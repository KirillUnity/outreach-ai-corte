Вставь этот файл целиком в новый Agent-чат в корне `C:\Work\PetAI`. Пункты 1 и 3 ТЗ в этом чате не делать.

```
ROLE
Ты дорабатываешь Outreach AI Cortex (этот репозиторий). Python 3.12, FastAPI, Poetry. 8 ГБ RAM. Эмбеддинги этой проверки — хеши, не нейросеть. Облачные токены, локальные модели, брокер и Kubernetes не использовать.

ИСТОЧНИК
Пункт «Проверка поиска по своим текстам» в C:\Work\CareerAgent\docs\cortex-dorabotka-tz.md.

УЖЕ ЕСТЬ
- backend/app/services/rag_service.py: HashEmbedder (sha256 → вектор фиксированной длины), RAG_MODE=mock. OpenAIEmbedder ходит в сеть только в real
- backend/tests/test_rag_service.py: _FakeCollection.query возвращает первые n документов в порядке вставки и игнорирует векторы. Эту заглушку для проверки качества не использовать: она нарисует успех без сравнения фрагментов
- Отдельной модели, которая пересортирует выдачу, в репозитории нет. Не добавлять

СДЕЛАТЬ

1. Фикстура backend/tests/fixtures/rag_questions.json
   Несколько учебных вопросов. У каждого вопроса есть текст вопроса, expected_id и rejected_id.
   Рядом фрагменты: id и текст. expected_id — фрагмент, который должен найтись. rejected_id — фрагмент, который к вопросу не относится и в выдачу попасть не должен.
   Тексты подбери так, чтобы косинус HashEmbedder реально ставил нужный фрагмент выше чужого. Если пара не разделяется хешем, поменяй тексты фикстуры, а не алгоритм ранжирования.
   Боевых ключей и вызовов OpenAI в фикстуре нет.

2. Функция evaluate_retrieval(questions) -> list[Result]
   Модуль backend/app/services/rag_quality.py.
   На вход вопрос, expected_id, rejected_id и набор фрагментов (из фикстуры или аргументом).
   Поиск: HashEmbedder, косинус к вопросу, без Chroma, без сети, без tiktoken-облака и без RAG_MODE=real.
   Успех вопроса: expected_id есть среди найденных id, rejected_id нет.
   Пустая выдача по вопросу, у которого фрагмент в наборе есть, — ошибка этого вопроса, не «так и задумано».
   Пустой список вопросов — не пустой успех и не молчание. Результат или исключение с текстом «набор пуст». Вызывающий код (тест) это видит как отказ проверки.
   Сигнатуры с типами. Короткий docstring в стиле Google.

3. Тест backend/tests/test_rag_quality.py
   - читает фикстуру и проходит: нужный id в выдаче, чужой нет
   - отдельный вызов с questions=[] даёт отказ «набор пуст», не зелёный пустой список
   - вопрос с известным фрагментом и пустой выдачей (подмени поиск так, чтобы он вернул []) помечается ошибкой
   Тест не открывает сокет и не требует Docker.

НЕ ДЕЛАТЬ
Reranker, кросс-энкодер, sentence-transformers, Ollama, PyTorch, смена боевого RAGService.search на другой эмбеддер, правка прод-индексации Chroma, Telegram, коммит без просьбы пользователя.

ПРОВЕРКА
poetry run pytest backend/tests/test_rag_quality.py backend/tests/test_rag_service.py -q

OUTPUT
Фикстура, функция, тест. Одной фразой: проверка сравнивает выдачу на учебных фрагментах и не зовёт модель.
```
